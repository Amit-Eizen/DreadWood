# DreadWood — Code Map

A reference for the defense: where everything lives, what each script does, and how they talk to each other.
_(Living document — we'll update it as we build.)_

---

## Overview
A 3D survival/horror game. The player (Brute) is built on **Unity StarterAssets — ThirdPersonController**,
and our scripts add combat, dodge, and stealth on top. One enemy brain (`MutantAI`) drives both the
zombies and the boss, and one central manager (`GameManager`) is what everything else talks to.

Content (cabin, trees, zombies, terrain) is **not placed by hand** — it's generated by **editor tools**
from the `Tools ▸ DreadWood` menu.

---

## 3 patterns you must know for the defense 🔑

1. **Central manager (Singleton):** `GameManager.Instance` is the single source of truth for health,
   win/lose, and the objective. Every script calls it:
   `GameManager.Instance.TakeDamage(x)` / `Heal(x)` / `Win()` / `Lose()` / `SetObjective("...")`.

2. **Static flags for cross-script signals:** instead of holding references, a script exposes a `static` flag:
   - `PlayerDodge.IsDodging` — read in `GameManager.TakeDamage` to grant i-frames during a dodge.
   - `PlayerStealth.IsStealthed` — read in `MutantAI.CanSeePlayer` to shrink detection range while sneaking.
   _(Why static? There is one player, so it's global state — simple and readable.)_

3. **Built on StarterAssets:** the player's movement/animation is Unity's; our scripts hang on top of it
   and tweak `ThirdPersonController.combatSpeedMultiplier` (e.g. slow down during a swing).

## Game scripts — `Assets/Scripts/`

### Core
| File | What it does | Key parts | Req |
|------|--------------|-----------|-----|
| **GameManager.cs** | Central state: health, objective, win/lose. Draws the HUD (HP top-left, objective top-right, red flash on hit) via `OnGUI`. | `TakeDamage` (respects i-frames), `Heal`, `Win`/`Lose` (freeze time + disable control), `Restart` | R8, R7 |
| **MainMenu.cs** | Menus: state machine (Main/Playing/Paused) + end screen (RESTART/QUIT). ESC to pause. | Freezes time + disables control in menus | R1 |

### Player (on top of StarterAssets)
| File | What it does | Req |
|------|--------------|-----|
| **PlayerCombat.cs** | Melee: left-click = combo (`attack1`→`attack3`), Shift+move+click = leaping run attack. Opens a "hit window" scanning a forward cone for `EnemyHealth`, adds slash VFX + brief hit-stop. | combat/fun |
| **PlayerDodge.cs** | Right-click = dash/roll with invulnerability. Exposes `static IsDodging`. | combat |
| **PlayerStealth.cs** | Ctrl = crouch/sneak. Exposes `static IsStealthed` (affects enemy vision). | R16 |
| **ThirdPersonFollowCamera.cs** | Third-person camera following `PlayerCameraRoot`, with a `SphereCast` to avoid clipping walls. | R19 (3rd-person side) |
| **ControlsHUD.cs** | Key legend via `OnGUI`, toggled with H. | R2 (partial) |

### Enemies
| File | What it does | Req |
|------|--------------|-----|
| **MutantAI.cs** | Enemy brain (zombie + boss). `Wander` (idle) / `ChaseAndAttack`. `CanSeePlayer` = range + vision cone + `Physics.RaycastAll` (with `sightBlockers` LayerMask), shrunk by `PlayerStealth.IsStealthed`. `SetGait` drives the Animator. `alwaysAggressive` = boss mode. | R13, R16, R17, R14 |
| **EnemyHealth.cs** | Enemy/boss HP: boss health bar + overhead bars on zombies, death (`die` trigger). | R8, enemies |
| **BossIntro.cs** | Boss-fight intro sequence. | boss |

### Interactions
| File | What it does | Req |
|------|--------------|-----|
| **HealthPickup.cs** | Trigger pickup → `GameManager.Heal`. | R3, R8 |
| **DoorController.cs** | Press Y to open a door (rotates a Transform). | interaction |
| **ObjectiveLight.cs** | Trigger that updates the objective / reveals the boss. | R3, R2 |

## Who talks to whom (flow)
```
                       ┌──────────────────┐
   PlayerDodge.IsDodging ───────────────▶ │                  │
   PlayerStealth.IsStealthed ──▶ MutantAI │   GameManager     │◀── HealthPickup.Heal()
                                  └──┬─────│   (Instance)      │
                          TakeDamage │     │  HP · Win/Lose    │──▶ HUD (OnGUI)
                                     ▼     └────────┬──────────┘
                            GameManager.TakeDamage           │ Win/Lose state
   PlayerCombat ──▶ EnemyHealth.TakeDamage                   ▼
                                                         MainMenu (end screen)
```
